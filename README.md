## ⚡ Core Portfolio Features

- **Cosmic Milky Way Starfield Engine**: Real-time HTML5 2D Canvas rendering of diagonal galactic dust bands, twinkling starlight particles, dynamic shooting meteors, and cursor starlight magnetism.
- **Top Reading Depth Progress Bar**: Sleek gradient scroll bar (`#00f0ff` to `#818cf8`) fixed at the top of the viewport reflecting page reading progress.
- **Interactive In-Page Specs & Architecture Modal**:
  - Instant modal inspection for all 17 hardware projects without navigating away.
  - **Embedded ASCII System Architecture Diagrams** showing data pipelines and telemetry signal flows.
  - **Hardware Bill of Materials (BOM)** tables with operating voltages and functional specs.
  - **Circuit Pinout Interconnect** tables with MCU pin mappings and hardware buses.
  - **Firmware State Machine & FreeRTOS Loop Summaries**.
  - One-click **Git Clone** command copier with floating toast confirmation.
- **Featured Repository Showcase (All 17 Projects)**:
  - Live category filter tabs (*Robotics & Kinematics*, *Industrial Automation*, *Embedded Firmware*, *Radar & Sensing*, *IoT & Telemetry*) with dynamic badge counters.
  - Instant live keyword search bar filtering microcontrollers, sensors, communication protocols, and titles.
  - Active counter pill: `Showing X of 17 Engineering Repositories`.
- **Technical Competency Matrix**: Six comprehensive panels covering microcontrollers, low-level languages, robotics toolchains, hardware bus protocols, wireless ecosystems, and EDA suites.
- **Executive Direct Contact Hub**: Click-to-copy email card for `alwintr2003@gmail.com`, direct LinkedIn gateway, and GitHub workspace links with live availability badge.
- **Optimized Performance**: Zero external heavy framework overhead, pure CSS3 glassmorphism, responsive across desktop, tablet, and mobile displays.

## 🚀 Local Development Instructions

To test or preview the portfolio locally:

```bash
# Clone repository
git clone https://github.com/ALWINTR/ALWINTR.github.io.git

# Navigate into directory
cd ALWINTR.github.io

# Start lightweight local HTTP server
python -m http.server 8000
```

Open a web browser and navigate to `http://localhost:8000`.
